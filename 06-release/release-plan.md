# DogTranslator Release Plan

## 1. Release Goal
Ship a Windows desktop MVP that demonstrates local dog-voice interpretation and experimental reverse expression output.

## 2. Packaging Assumption
- First release format: Windows desktop build output packaged as zip

## 3. Required Release Contents
- application executable
- runtime output
- README
- known limitations
- usage instructions

## 4. Required Disclosures
- Output is an experimental interpretation, not a scientifically validated translation.
- Reverse mode is playful and exploratory.
- Audio is processed locally in the MVP.

## 5. Post-Release Backlog
- Android target
- iPhone target
- learned model provider integration
- persistent history
- richer playback behavior

## 6. Release Scope Revision
### Still candidate for pre-release inclusion
- waveform visualization during recording
- microphone device selection
- richer Japanese emotional labels in forward mode

### Defer unless a smaller concrete version is approved
- breed selection
- higher-fidelity dog-voice rendering
