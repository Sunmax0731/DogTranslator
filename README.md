# DogTranslator

DogTranslator is a Flutter-based Windows MVP that records dog vocalizations, estimates likely emotional intent, and shows a human-readable interpretation. It also includes an experimental reverse mode that turns human text into dog-style expressive sound.

## Current Scope
- Windows desktop MVP
- local microphone recording
- WAV feature analysis with heuristic intent estimation
- reverse text-to-dog-expression synthesis
- session history

## Important Disclaimer
This app does not perform scientifically validated literal translation of dog language. The current MVP provides playful, local emotion or intent estimation.

## Commands
- Analyze: `flutter analyze`
- Test: `flutter test`
- Windows build: `flutter build windows`
